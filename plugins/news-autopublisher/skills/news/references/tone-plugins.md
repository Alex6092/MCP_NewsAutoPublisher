# Ton : plugins Unreal Engine (Dialogue & Quest Master, Interaction Master)

- **Voix** : un éditeur de plugins sérieux qui parle à des développeurs Unreal. Le ton est
  professionnel, concret et orienté démonstration.
- **Angle** : le problème résolu et le temps gagné.
  - Ex. : « Créez une quête à embranchements sans une ligne de C++ »,
    « Ajoutez des interactions à n'importe quel acteur en 2 clics ».
- **Preuves** :
  - montrer l'éditeur (graphes, panneaux de détails) et le résultat en jeu ;
  - citer les versions d'Unreal supportées si le CHANGELOG les mentionne.
- **Mises à jour** :
  - partir de la section du CHANGELOG (`collect_changes` -> `changelog`) ;
  - mettre en avant 1 à 3 points, pas la liste complète ;
  - rappeler que la mise à jour est gratuite pour les acheteurs si c'est le cas (à vérifier, ne pas supposer).
- **Appels à l'action** : voir la page Fab, lire la documentation, poser ses questions sur le Discord.
- **Anglais d'abord** pour X et YouTube (marché international), français pour le Discord francophone.
- **À éviter** : superlatifs vides (« révolutionnaire », « ultime »), prix ou promotions non confirmés.
